# HTML download indexer

Category `indexer`: `search_start -> http -> search_end`; for detail-only links, add `http -> loop`, `loop.loop_start -> http`, its `output -> loop.loop_continue`, `loop.output -> search_end`. Batch needed schemas (include_examples=false); mode=search enforces search_end. Server-rendered HTML, page-number pagination; no JavaScript, crawling, automatic login or CAPTCHA (login: indexer_auth). Observe search/page parameters, selectors, stable ID, title and download links. A clipped probe `text` is not a blocked page: use `formatter`, e.g. `{"html": {{ response.text[2000:3000]|tojson }}}`, then inspect further slices or extract observed attributes/text. Keep extraction small (8000 rendered bytes). It reads the bounded body; inspect `body_complete`. XPath elements are nodes, not HTML strings; use `/@href` or `string(.)`. Parenthesize filtered lists before slicing: `(html|xpath_all('//tr'))[:3]`.

Search http: GET, `quote('')` keyword, observed page parameter, httpx client (curl_cffi `response.url` is text). For fixed source pages, map `(page_num-1)*page_size` to source pages, fetch all needed pages, then slice once. Never require the source's page size or skip its remaining rows: assistant searches use 1-20, plans use batch_limit. Formatter: `{"status": {{ response.status_code }}, "login": {{ (response.text|xpath_first('//form[@id="login"]') is not none)|tojson }}, "cards": [{% for c in response.text|xpath_all('//li[@class="item"]') %}{% if not loop.first %},{% endif %}{"id": {{ c|xpath_first('./@data-id')|tojson }}, "title": ..., "detail": {{ response.url.join(c|xpath_first('.//a/@href'))|string|tojson }}}{% endfor %}]}`. IDs from source data, never positions.

Detail loop: expression `{{ cards[:page_size] }}`, varname `card`; http GET `{{ card.detail }}`, formatter `{"details": { {{ card.id|tojson }}: {"link": {{ ...magnet or joined .torrent href...|tojson }}}}}`.

search_end: login/error pages `{"error": "login_required"}`/`{"error": "status 503"}` without items (invalid, not empty); else items from `cards[:page_size]` with `"link": (details|default({})).get(card.id, {}).link` or the card's own link; none: `{"items": []}`. Omit total unless stated (page count is not a total).

Validate exact templates: formatters via probe or `response` fixture `{text, url, status_code}`; search_end with mode=search, context `downloads: true`, page_num/page_size: first/next with `previous_ids`, small/cross-boundary pages, empty, login/error, missing-optional and missing/relative-link samples. Links: magnet, BT hash or absolute torrent URL; detail/player pages are not links; shape is not proof. Fix and recheck at most twice; report unresolved selectors/pagination. Preview via Keep/Revert; the user publishes, then plans can search it.
